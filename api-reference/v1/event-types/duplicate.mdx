## What the copy gets

The copy gets the same settings, hosts, booking form fields, locations and notifications as the original.

The name ends with `(Copy)` and the slug ends with `-copy`. If a copy already exists, the next copy gets a number, for example `(Copy 2)` and `-copy-2`.

## Limits

- You can only duplicate event types on your own account. Another account's event type returns `403 access_denied`.

A successful duplicate returns `201` with the new event type.
