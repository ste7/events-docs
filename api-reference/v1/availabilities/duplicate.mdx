## What the copy gets

The copy gets the same timezone and hours as the original. You give the copy a new `name`.

The copy is never the default schedule. Your default schedule does not change.

## Limits

- `name` is required. A request without it returns `422`.
- You can only duplicate schedules on your own account. Another account's schedule returns `403 access_denied`.

A successful duplicate returns `201` with the new schedule.
